Introduction to Noxiouse Engine

Welcome to the Noxiouse Engine User Manual & Gameplay Programming Guide. Whether you are building an atmospheric action game, a massive open-world RPG, or a high-fidelity cinematic simulation, this guide teaches you how to use Noxiouse's editor, visual tools, and C# scripting API to bring your game to life.

TIP

Looking for low-level engine internals?

If you are contributing to the engine's C++20 / Vulkan 1.4 core or inspecting the 489 source files, click the ⚙️ Engine Architecture & 489 Files button in the top right. This manual focuses purely on creating games, authoring content, and writing gameplay code.

What Makes Noxiouse Unique?

  1. GPU-Driven Visibility Buffer & Unified Geometry Arena: Traditional engines choke on thousands of draw calls and material switches. Noxiouse uses a 64-bit Visibility Buffer with Nanite-style Cluster LOD DAG streaming, drawing millions of triangles with near-zero CPU driver overhead.
  2. Large World Coordinates (LWC): Every entity translation is stored in 64-bit double precision. You can build worlds thousands of kilometers across with millimeter-level physics precision, with zero floating-point camera jitter.
  3. Stateful C# Hot Reload: Gameplay scripts are written in standard C# (.NET 9). Save your script in VS Code or Visual Studio, and Noxiouse reloads the code live in the editor in milliseconds while preserving your player position and component state.
  4. Decoupled Real-Time Hardware Ray Tracing & ReSTIR: Enjoy soft ray-traced sun shadows (denoised by NVIDIA NRD SIGMA), specular reflections (REBLUR / RELAX), and dynamic Global Illumination (Screen-Probe GI, Cascaded DDGI, and RTXDI ReSTIR DI/GI) alongside full NVIDIA DLSS Super Resolution and Ray Reconstruction.
  5. Jolt 3D Physics Built-in: Industry-leading multi-threaded 3D physics with double-precision Large World Coordinates, rolling resistance for spheres/cylinders, virtual character controllers, and 7 constraint types.
  6. Visual Animation Graphs & Sequencer: Author state machines, 1D/2D blend spaces with footstep phase synchronization, montage slots, and cinematic cutscenes with an 11-track curve editor.
